# 미적분과 자연현상 연구계획서 에이전트

자연현상에 대한 아이디어를 **연구 질문 → 미적분 모델 → 자료 수집 → 분석 → 연구계획서**로 구체화하는 프로젝트입니다.

고등학생의 탐구 활동을 기본 대상으로 하며, 학습 범위와 기간에 맞게 설계를 조정합니다. 프로젝트의 프롬프트형 지침은 [AGENTS.md](AGENTS.md)에 있습니다.

## 시작하기

1. 이 저장소를 내려받거나 복제합니다.
2. 프로젝트 폴더를 사용하는 에이전트에서 열고 `AGENTS.md`를 지침으로 적용합니다.
3. 연구 아이디어와 학년, 연구 기간, 사용할 수 있는 장비를 입력합니다.
4. 제안된 연구 조건을 확인하고 계획서를 작성하거나 수정하도록 요청합니다.

기본 결과는 `outputs/research-proposal.md`에 저장하도록 지침에 지정되어 있습니다. 파일 저장 기능이 없는 환경에서는 계획서 전문을 대화로 제공합니다.

## 이렇게 요청해 보세요

> 따뜻한 물이 식는 속도를 미분으로 연구하고 싶어. 고등학생이고 기간은 4주야. 온도계와 같은 컵 3개를 사용할 수 있어. 연구계획서를 작성해줘.

> 강우 강도의 시간별 자료를 적분해서 누적 강수량을 구하는 연구를 하고 싶어. 자료의 단위와 적분 방법도 설명해줘.

> 비가 내린 뒤 토양 수분이 감소하는 현상을 연구하고 싶어. 센서가 없을 때 가능한 방법부터 제안해줘.

주제를 정하지 못했다면 “미적분과 자연현상을 연결하는 4주 연구 주제 3개를 비교해줘”라고 요청할 수 있습니다.

## 저장소 구성

| 파일 | 내용 |
|---|---|
| [AGENTS.md](AGENTS.md) | 역할, 입력 확인, 연구 유형, 미적분 검토 기준, 출력 형식 |
| [예시 연구계획서](examples/cooling-research-proposal.md) | 따뜻한 물의 냉각을 주제로 작성한 실험 계획 |
| [.gitignore](.gitignore) | 개인 작업 결과와 로컬 설정 등의 기본 제외 규칙 |

## 만들어지는 계획서

연구 요약과 조건, 제목, 동기, 목적과 질문, 이론 및 미적분 연결, 가설, 구체적인 연구 방법과 기록표, 일정, 예상 결과, 한계, 안전 및 참고자료를 포함합니다.

미분과 적분을 모두 사용할 필요는 없습니다. 질문에 필요한 개념을 선택하며, 데이터가 없는 단계에서 실험 결과나 참고문헌을 만들어 내지 않도록 설계했습니다.

## 예시 읽기

[냉각 연구계획서](examples/cooling-research-proposal.md)는 실행 전 설계를 보여 주는 예시입니다. 실제 측정값이나 검증된 연구 결과를 담고 있지 않습니다. 장비와 예비 실험 결과에 맞춰 측정 조건을 조정해 사용하세요.

## 파일 관리

생성된 계획서는 `outputs/`에 저장되며 기본적으로 Git 추적에서 제외됩니다. `data/`, `private/`, 환경 설정 파일도 제외합니다. 제외 규칙은 이미 추적 중인 파일에는 적용되지 않으며, 모든 민감 자료를 자동으로 감지하지는 않습니다. 공개할 파일의 내용을 확인한 뒤 필요한 파일만 추가하세요.
